IBM Plex font files in this directory are the Latin subsets served by Google Fonts
for the SUOOTER desktop report shell.

Family: IBM Plex Sans / IBM Plex Sans Condensed / IBM Plex Serif
License: SIL Open Font License 1.1 (OFL-1.1)
Source: https://fonts.google.com/specimen/IBM+Plex+Sans
        https://fonts.google.com/specimen/IBM+Plex+Sans+Condensed
        https://fonts.google.com/specimen/IBM+Plex+Serif

The OFL allows bundling and self-hosting. Keep this notice with the font files.
Chinese text falls back to PingFang SC / Noto Sans SC / Microsoft YaHei.
