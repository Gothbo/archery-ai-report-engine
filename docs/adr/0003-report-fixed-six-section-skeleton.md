# 报告采用固定六段骨架，每段必出、缺失即标注

报告固定包含 `window_score` / `level` / `data_integrity` / `wind_bands` / `sample_gate` / `auxiliary` 六段，按"结论 → 依据 → 辅助"排序；任一段即使无数据也照常出现，内容为显式缺失说明，而非静默省略。

## Context

缺数据或降级期下，原报告退化为 1 段（P0-1），与"3 分钟抓住核心问题"目标冲突。ADR-0002 已定"不静默省略"原则，本 ADR 定其具体形态。

## Decision

固定六段骨架（顺序即优先级）：

1. `window_score` —— 含脱靶均环 + 有效箭均环 + 脱靶率 + 内十/远弹/命中
2. `level` —— 有 MDC 出判定；降级期出滚动基线水平描述
3. `data_integrity` —— 本窗口缺失项显式标注
4. `wind_bands` —— 有风数据时出；无则并入 `data_integrity`
5. `sample_gate` —— 达标也显式"样本达标"，不达标出提示
6. `auxiliary` —— 备注 + 平台期，有则出

## Considered Options

- 极简 3 段：仍偏薄，不足以支撑核心问题定位。
- 标准 6 段（选中）：覆盖成绩 / 水平 / 数据边界 / 依据 / 样本 / 辅助。
- 全量 8+ 段：引入依赖 MDC 的趋势与建议，超出阶段 1 范围。

## Consequences

- 报告段集合成为对外契约；前端按固定 key 渲染，须容忍"无数据"段。
- 后续新增段需同步更新阶段 1 验收标准。
