# 数据缺失与 MDC 降级期：显式标注，不静默省略、不输出方向判定

采样数据（风速 / 心率 / 撒放）缺失时，报告显式标注"本窗口无 X 数据"而非静默省略该段；`mdc_source` 为空（降级期）时，报告不输出进步/退步判定，改出明确的降级提示与基于滚动基线的水平描述。

## Context

真实数据中：风速源止于 2025-03-13、运动员A 2025-04 无心率、`mcr_t` 全库不可得。原实现静默省略无数据段，缺数据窗口的报告退化为一句话；降级期下无判定却也不声明，容易"看起来像有结论"。

## Decision

- 缺失项：该段仍出现，内容为显式缺失说明（含缺失原因/范围）。
- 降级期：不出现 MDC 判定词，出现"降级期，暂无进步/退步判定"提示 + 滚动基线水平描述。
- `mcr_t` 等不可得数据移出阶段 1 报告范围，报告不出现相关结论。

## Considered Options

- 静默省略（原行为）：报告单薄，教练误以为"没内容"。
- 扩展数据接入补齐缺失：超出报告层范围，依赖外部数据/开发，不作为阶段 1 前置。
- 显式标注（选中）：报告层可独立完成，且如实传达数据边界。

## Consequences

- 报告段集合从"有数据才出"变为"固定骨架，缺失即标注"。
- 与 ADR-0001 共同确定 `window_score` 之后报告骨架的形态，是后续报告结构决策的前置。
