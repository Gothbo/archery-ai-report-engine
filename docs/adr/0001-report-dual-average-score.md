# 报告均环采用双口径

报告的成绩段同时给出「含脱靶均环」与「有效箭均环」，并单独标注脱靶率，让教练区分"打不准"与"脱靶多"。此前只呈现含脱靶均环，会把脱靶占比混进水平判断。

## Context

真实数据下脱靶占比显著：葛靖 W01 脱靶率 46%，含脱靶均环被拉到 4.23，剔除脱靶后约 8.0；相邻窗口从 4.23 到 8.28 的波动主要由脱靶占比驱动，而非着点质量。单一口径会被误读为水平骤升或骤降。

## Decision

`window_score` 段并列输出：含脱靶均环、有效箭均环、脱靶率（新增独立指标）。

## Considered Options

- 只保留含脱靶均环：被脱靶占比污染，误读水平。
- 只保留有效箭均环：丢失"脱靶多"这一教练最关注的问题。
- 双口径并列（选中）：两个口径各回答一个问题，脱靶率补足归因。

## Consequences

- 指标层新增 `effective_avg_score` 与 `miss_rate`。
- `window_score` 段契约变更，前端与阶段 1 验收标准需同步。
- 报告缓存按 `mdc_source` 版本失效；口径变更须递增该版本，否则旧缓存仍返回单口径。
